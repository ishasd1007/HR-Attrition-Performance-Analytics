# HR Attrition & Performance Analytics

## Overview
An interactive HR analytics dashboard built using Power BI to explore employee attrition patterns and performance-related factors.

## Tools Used
- Microsoft Power BI
- Microsoft Excel

## Dataset
IBM HR Analytics Employee Attrition & Performance dataset.

## Key Metrics
- Total Employees: 1,470
- Employees Left: 237
- Attrition Rate: 16.12%

## Dashboard Features
- Department-wise attrition analysis
- Attrition by overtime
- Work-life balance and job satisfaction analysis
- Performance rating and job involvement analysis
- Interactive filters for department, gender, and job role

## Key Learning
Practiced data analysis, KPI creation, interactive visualizations, and dashboard development using Power BI.
